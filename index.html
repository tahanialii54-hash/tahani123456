أشكال الوراثة في لغة JavaScript

تطبيق عملي لمفاهيم البرمجة الكائنية (OOP) بأسلوب تعليمي متدرج

1

وراثة فردية (Single)

تعني كلاس يَرِث من كلاس واحد فقط بشكل مباشر.

Class A ↓ Class B
2

وراثة متتالية (Multilevel)

تعني كلاس يَرِث من كلاس والذي بدوره يَرِث من كلاس آخر.

Class A ↓ Class B ↓ Class C
3

وراثة هرمية (Hierarchical)

تعني أن الكلاس الرئيسي موروث من قبل أكثر من كلاس فرعي.

Class A (الأب)
↙ ↘
Class B Class C

الواجهة الأولى: كلاس الأب الأساسي Person

الأساس

تحتوي هذه الواجهة على التعريف الأساسي لكلاس الأب وتحديد الخصائص العامة.

الواجهة الثانية: الوراثة الفردية Student

تَرِث من Person

استقبال البيانات من المستخدم، إنشاء كائن الابن، وطباعة المخرجات.

الواجهة الثالثة: الوراثة المتتالية GraduateStudent

تَرِث من Student

استكمال الوراثة عبر 3 مستويات وإنشاء كائن الحفيد الجامع لكل الخصائص.

الواجهة الرابعة: الوراثة الهرمية Teacher

تَرِث أيضاً من Person

إنشاء كائن من كلاس فرعي آخر (المعلم) يشارك نفس كلاس الأب مع الطالب.
